2026-09-21 用户核对后修改：左侧 Library 与各个设备播放列表显示名称和歌曲总数。点击 Library，中央沿用普通列表的顶部与列标题样式，仅填充真实可用字段，不强制新增 Media kind 列。Library 包含全部记录，不另设 All/Music/Audiobooks 页签或分类数量。点击设备 playlist，按数据库成员顺序显示曲目；有声读物通过设备已有 Smart Playlist 浏览，只读取已保存成员，不创建、重算或修复智能规则。底层 Media Kind 与未来导入类型选择不变。

顶部不新增 Library 大标题、设备摘要或 Refresh 横条。Refresh 放到设备节点右键菜单；Read-only、读取状态与错误在设备概览显示。右上区域继续现有歌曲封面与播放信息行为，设备浏览、刷新及状态更新不得覆盖它或改变播放目标。

2026-09-21 用户确定：Device overview 放在右下区域，作为现有 Lyrics / Track details 之外的第三个页面（隐藏入口，以鼠标中键切换）。只有中央处于 iPod 上下文（左侧选中设备、Library 或设备播放列表）时才把设备页加入中键轮换；仅连接 iPod 不足以让它出现。进入 iPod 上下文只增加中键轮换页面，不自动切离用户正在查看的歌词或歌曲信息。用户用中键切换到 Device 后才显示当前所选设备的容量、可用空间、只读状态与必要错误，不展示分类数量。

切回普通播放列表/专辑视图或服务消失时从中键轮换移除 Device 页；若它正被选中，回到进入 Device 前的 Lyrics / Track details，歌词不可用时按既有规则回退 Track details。若用户仍停留于已移除设备的浏览上下文，Device 页可显示 disconnected，清除在线容量/快照数据，不自动抢焦点。切换两台设备时概览跟随选中的设备，绝不改变播放目标。页面可用性是上下文状态，不保存成全局永久第三页。

006 不增加写入、评分修改、拖入、删除、初始化、Eject 或 Smart 编辑入口。双击设备曲目与 Enter 不调用现有 playlist 播放命令：当前合同没有安全媒体解析接口，不能从相对路径猜测盘符。需要播放时先另行确定服务扩展和验收范围。

## 状态与交互

| 状态 | 可见行为 |
| --- | --- |
| 服务缺失 | 隐藏 Devices；正常 Playlists 保持可用 |
| 只有旧 ABI | 显示组件版本不支持浏览；不伪装空曲库 |
| 正在读取 | 设备概览显示 Reading；Refresh 合并请求/禁用重复点击；旧表标为不可用 |
| ReadyReadOnly | 显示真实库、容量和只读标识；允许选择、滚动、文本筛选与浏览列表 |
| NotMounted/FormatPending/错误 | 显示服务原始状态语义，容量未知显示 unavailable；无伪造零曲目 |
| 有效空库 | 显示 0 tracks，与读取失败区分 |
| 移除或失效 | 清除当前在线引用，显示 Device disconnected；保留普通 playlist 及播放状态 |
| 同名或重复项 | 按 provider token 区分，不能按显示名去重；选择不跨 token 迁移 |

侧栏上下区各自滚动，分隔条可拖动并按 FooCrate 既有设置模型保存比例；首次默认 Playlists 占侧栏上方约三分之二。键盘上下选择节点，左右展开/收起，Tab 转移区域焦点；设备表只读，Delete/F2/Ctrl+V 不沿用普通 playlist 的修改处理。

窄窗口优先保留 Title、Artist 和状态，Album 可水平滚动；右栏复用现有可拖宽度，不新建浮窗。颜色、焦点框、字号与 DPI 使用现有 FooCrate 主题和度量，高对比度不能只靠颜色区分状态。

## 程序逻辑与失败恢复

1. 消费者在主线程枚举 FooPodBridge provider，再查询只读扩展；查询失败属于 service missing/incompatible，不通过 DLL 文件名猜测。
2. 订阅对象跟随面板生命周期；回调只投递一次主线程更新，窗口销毁先取消订阅，晚到消息检查 lifetime。
3. 接收 catalog 后以 token + generation + revision 建立当前选择，保留不可变 Library 引用；回调表明失效即暂停设备操作。
4. 将 track ID 建索引，playlist 成员通过 ID 映射，保留顺序；不存在的成员显示数据错误，不用别的曲目替代。
5. 设备列表和普通播放列表使用不同模型与命令分派，不能调用 playlist_manager 创建假 Library 或覆盖当前 playlist。
6. 快照复制/投影与绘图分离，分批主线程消息每次最多处理 128 个内存条目；绘图、滚动、鼠标移动不进行磁盘/USB I/O。每批检查快照有效性，取消和新 revision 使旧投影失效。
7. Refresh 只调用服务排队入口，失败保持可解释状态，用户手动再试；不自动循环重扫。
8. 文案和诊断不输出原始身份、设备路径、曲名或完整数据库；曲目元数据只留在正常本地 UI。
9. 设备浏览上下文、右下页签选择与正在播放歌曲是独立状态。第三页切换复用现有歌词宿主生命周期，不停止/重启播放，不更改右上歌曲来源。测试覆盖进入/离开 iPod 上下文、服务缺失、设备移除、跨设备切换、歌词缺失回退及设备概览显示期间切歌。
